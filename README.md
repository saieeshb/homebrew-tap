# saieeshb/tap

Homebrew formulae by [@saieeshb](https://github.com/saieeshb).

```bash
brew tap saieeshb/tap
brew trust saieeshb/tap   # newer Homebrew asks you to trust third-party taps once
brew install unabridged
```

| Formula | What it is |
|---|---|
| [`unabridged`](https://github.com/saieeshb/unabridged) | Export AI coding agent chats (Claude Code, Codex) to Markdown, HTML or JSON. Formerly `cc-exporter`. |
